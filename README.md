# Fit Log

Fit Log is a workout library and workout planning web application built with Next.js.

## Features

- Workout Library
- Search workouts
- Dynamic workout details
- Add workouts to Today's Plan
- My Plan page
- LocalStorage support
- Mark workouts as completed
- Progress tracking
- Loading state
- Error handling
- Toast notification
- Responsive design
- API-based workout data

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Context API
- LocalStorage
- REST API
